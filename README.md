# InternNova-Internship

# Week 1 – Python Fundamentals for Data Analytics

A collection of beginner-friendly Python programs covering the core fundamentals 
needed for data analytics: variables, data types, operators, control flow, loops, 
functions, string/collection operations, file handling, and a mini project.

## 📂 Contents

| File              |         Task  |      Description |
|-------------------|---------------|------------------|
| `task1_basics.py` | Python Basics | Takes user input (Name, College, Branch) and displays formatted output |
| `task2_datatypes.py` | Variables & Data Types | Demonstrates int, float, str, and bool using `type()` |
| `task3_operators.py` | Operators | A calculator performing +, −, ×, ÷, and modulus |
| `task4_conditionals.py` | Conditional Statements | Grades marks using if / elif / else |
| `task5_loops.py` | Loops | for-loop counting, multiplication tables, while-loop even numbers |
| `task6_functions.py` | Functions | User-defined functions for square and average |
| `task7_strings_collections.py` | Strings & Collections | String methods, lists, tuples, dictionaries, and sets |
| `task8_file_handling.py` | File Handling | Writes and reads a text file |
| `task9_student_records.py` | Mini Project | Menu-driven Student Record Management System (add/display/search/delete) |

## ▶️ Run any file
```bash
python3 <filename>.py
```

## 🛠️ Requirements
- Python 3.x (no external libraries needed)


# Week 2 – NumPy, Pandas & Visualizations Data Analytics

A collection of Python programs covering NumPy, Pandas & Visualizations fundamentals for data analytics: 
array operations, indexing/slicing, mathematical & statistical functions, DataFrames, data 
inspection, filtering/sorting, missing value handling, merging/GroupBy/pivot tables, data 
export, and a mini data analysis project with visualizations.

## 📂 Contents

| File | Task | Description |
|------|------|-------------|
| `task1.py` | NumPy Introduction & Arrays | Creates 1D/2D arrays and displays shape, size, and dtype |
| `task2.py` | Indexing, Slicing & Reshaping | Demonstrates array indexing, slicing, and reshaping into different dimensions |
| `task3.py` | Mathematical & Statistical Operations | Element-wise arithmetic and statistical functions (mean, median, std, etc.) |
| `task4.py` | Pandas Series & DataFrame | Creates a Series and a student DataFrame, adds a new column |
| `task5.py` | Reading & Inspecting Data | Reads a CSV and inspects it with head(), tail(), info(), describe() |
| `task6.py` | Selecting, Filtering & Sorting | Selects columns/rows, filters with conditions, sorts data |
| `task7.py` | Handling Missing Values | Identifies, counts, drops, and fills missing values |
| `task8.py` | Merge, Concatenate, GroupBy & Pivot Table | Merges/concatenates datasets, GroupBy aggregation, pivot table |
| `task9.py` | Exporting Data | Processes and exports the cleaned dataset to CSV |
| `task10_mini_project.py` | Mini Data Analysis Project | End-to-end analysis with insights and 4 matplotlib visualizations |
| `students.csv` | Dataset | Student performance dataset (with intentional missing values) |
| `departments.csv` | Dataset | Branch-wise department info, used for merging |

## 📊 Visualizations (Task 10)
- Average marks by branch (bar chart)
- Average attendance by branch (bar chart)
- Distribution of student marks (histogram)
- Marks vs attendance (scatter plot)

## ▶️ Run any file
```bash
python <filename>.py
```
