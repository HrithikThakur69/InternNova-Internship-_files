# InternNova-Internship

# Week 1 – Python Fundamentals for Data Analytics

A collection of beginner-friendly Python programs covering the core fundamentals 
needed for data analytics: variables, data types, operators, control flow, loops, 
functions, string/collection operations, file handling, and a mini project.

## 📂 Contents

| File              |         Task  |      Description |
|-------------------|---------------|------------------|
| `task1_basics.py` | Python Basics | Takes user input (Name, College, Branch) and displays formatted output |
| `task2_datatypes.py` | Variables & Data Types | Demonstrates int, float, str, and bool using `type()` |
| `task3_operators.py` | Operators | A calculator performing +, −, ×, ÷, and modulus |
| `task4_conditionals.py` | Conditional Statements | Grades marks using if / elif / else |
| `task5_loops.py` | Loops | for-loop counting, multiplication tables, while-loop even numbers |
| `task6_functions.py` | Functions | User-defined functions for square and average |
| `task7_strings_collections.py` | Strings & Collections | String methods, lists, tuples, dictionaries, and sets |
| `task8_file_handling.py` | File Handling | Writes and reads a text file |
| `task9_student_records.py` | Mini Project | Menu-driven Student Record Management System (add/display/search/delete) |

## ▶️ Run any file
```bash
python3 <filename>.py
```

## 🛠️ Requirements
- Python 3.x (no external libraries needed)
